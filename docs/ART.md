# Art manifest

Original production art generated using the built-in ImageGen tool. All four outputs were visually inspected for character identity, hands, composition and clean presentation. Source originals remain in Codex generated_images; final project assets are copied below. No CLI fallback, API key, existing-franchise assets or remote runtime assets were used.

Unmodified PNG originals are preserved in `art-source/`. Runtime WebP files retain the original dimensions and use quality 0.92 encoding. `node tools/encode-art.cjs` reproduces the encoding through headless Chromium. Total runtime image bytes: 1,523,238 (originals: 10,325,522).
