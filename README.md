# SKYCHORD · 마지막 열차의 합창

하늘 철도를 여행하며 세 동료의 기술을 화음으로 엮는 오리지널 3D 파티 RPG입니다. 미라, 세나, 노아와 함께 노을역에서 별빛 관측소까지 이동하며 침묵한 네 구역의 릴레이를 되살립니다.

## 실행

`index.html`을 직접 열면 실행됩니다. 외부 CDN이나 서버 연결이 필요하지 않습니다. 데스크톱의 WebGL2 지원 브라우저를 기준으로 제작했습니다.

개발 서버: `npm install` 후 `npm run build`, `npm run serve`. 서버 주소는 `http://127.0.0.1:4174/`입니다. 이 명령은 브라우저를 자동으로 열지 않습니다.

## 조작

| 상황 | 키 | 동작 |
| --- | --- | --- |
| 탐험 | WASD / 방향키 | 카메라 기준 이동 |
| 탐험 | Shift | 질주 |
| 탐험 | Q / E | 카메라 회전 |
| 탐험 | F / Enter | 가까운 대상 조사 |
| 탐험 | Tab | 지도·의뢰·동료 기록 |
| 전투 | Q / E | 동료 선택 |
| 전투 | 1 / 2 / 3 | 기술 선택 |
| 전투 | Tab | 적 대상 변경 |
| 전투 | Space / Enter | 선택한 기술 실행 |
| 전투 | F | 공명 100일 때 앙코르 |
| 공통 | Esc | 일시정지 / 돌아가기 |
| 공통 | M | 음향 켜기·끄기 |

화면 버튼과 모바일 터치 조작도 제공합니다. 진행 기록은 브라우저의 로컬 저장소에 보관됩니다.

## 합주 규칙

동료 세 명이 한 번씩 행동하면 적이 예고한 기술이 발동합니다. 서로 다른 세 음은 **BREAK**로 충전 공격을 끊고, 같은 세 음은 **ECHO**로 체력과 방패를 회복합니다. 방패는 해당 적 행동이 끝나면 사라집니다. 공명이 100%에 도달하면 행동 횟수를 쓰지 않는 **앙코르**를 연주할 수 있습니다.

네 지역, 16개 교전, 네 수호자, 여섯 의뢰와 동료 강화가 포함됩니다. 전투 뒤 일부 체력을 회복하며, 캠프에서는 전원을 회복합니다. 패배하면 진행을 잃지 않고 재도전할 수 있습니다.

## 제작

- 캐릭터와 공간: Three.js를 이용한 오리지널 절차적 3D 모델
- 캐릭터 원화·타이틀: 내장 ImageGen 도구로 생성한 오리지널 이미지, [프롬프트와 경로](docs/ART.md)
- 오디오: Web Audio로 합성한 음악과 효과음
- 런타임: 하나의 로컬 `game.js` 번들, 상대 경로 이미지
- 라이브러리: Three.js MIT 라이선스, `licenses/three.txt`

설계와 모듈 계약은 [CONTRACT.md](docs/CONTRACT.md), 서사는 [NARRATIVE.md](docs/NARRATIVE.md)에 기록했습니다.

## 개발 검증

`npm run test:all`은 전투·성장, 로컬 파일/하위 경로 로딩, 입력·오디오, 모바일·저장·패배 복구와 엔딩까지의 전체 여정을 검사합니다. `npm run test:performance`는 별도의 헤드리스 성능 측정입니다. 브라우저 검증에 Playwright Chromium이 필요하며, 최초 설치는 `npx playwright install chromium`입니다.

`npm run pack`은 itch.io 업로드용 `dist/skychord-web.zip`을 만듭니다.

원본 PNG는 `art-source/`, 가벼운 웹용 이미지는 `assets/`에 보관합니다. `node tools/encode-art.cjs`로 같은 해상도의 WebP 파일을 다시 만들 수 있습니다.
